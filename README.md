# PriamyKuriér

Modern courier marketplace concept for Slovakia with a web platform and app
preview. The experience is English-first with Slovak localization planned.

## What's included

- Web landing page describing the full platform workflow
- Quote calculator with minimum rate enforcement
- App preview showcasing key screens (jobs, tracking, proof, accounting)
- Visual design using sage green, white, grey, and black

## View the website and app preview

Open the files directly in your browser:

- `index.html` for the website
- `app.html` for the app preview

Or run a simple local server:

```bash
python -m http.server 8080
```

Then visit:

- http://localhost:8080/index.html
- http://localhost:8080/app.html
